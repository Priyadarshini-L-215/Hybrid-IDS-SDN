# Sentinel Core Dashboard (React 19)

A high-performance, real-time security telemetry interface for the **Sentinel Core IPS (V4)**. Engineered for professional SOC environments with a focus on data density, visual clarity, and reactive speed.

## 🚀 Enterprise Features

*   **Sentinel Neural Stream**: Low-latency WebSocket integration with the **FastAPI** relay for instantaneous threat visibility.
*   **Active Mitigation Feedback**: Real-time status indicators for kernel-level blocking actions (`ipset`) and stateful correlation alerts.
*   **Unified Architecture**: Single-port deployment (3000) hosting both the static assets and the API/WebSocket relay.
*   **Professional SOC Aesthetic**: A premium "Sentinel Core" glassmorphic design system built with **React 19** and **Vite**.
*   **Attack Lab**: Integrated Nmap orchestration interface for security testing and simulation data generation.
*   **XAI Visualization**: Detailed breakdown of SHAP feature importance for every machine learning classification.

## 🛠️ Development

### Environment Setup
```bash
# Install core dependencies
npm install

# Launch development environment (HMR enabled)
npm run dev
```

### Configuration
The system uses **Vite** for optimized module bundling. In production, the UI is served by the FastAPI relay on `http://127.0.0.1:3000`. In development, Vite proxies API requests to the same backend.

## 🧭 Alert Sources

*   **Real IDS alerts**: Streamed live from Suricata and the ML Engine via the Redis-backed pipeline.
*   **Simulation alerts**: Generated by the Attack Lab and displayed with a simulation badge to maintain SOC operational clarity.

## 📜 Repository Scripts

- `npm run dev`: Executes the local development server with Hot Module Replacement.
- `npm run build`: Generates production-ready, minified assets in the `/dist` directory.
- `npm run lint`: Validates code quality and consistency.
- `npm run preview`: Previews the production build locally.
